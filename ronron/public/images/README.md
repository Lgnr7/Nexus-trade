Déposez ici les photos produits (JPG ou WebP, carrées, ~1000 × 1000 px),
puis renseignez le champ `image` du produit dans `data/products.json`, par
exemple `"image": "/images/source.jpg"`.

Utilisez uniquement des photos que vous avez le droit d'exploiter : les
vôtres, ou celles que le fournisseur autorise explicitement pour la revente.
